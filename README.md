# 👤 AMO South Africa - Official Landing Page

> A premium, high-performance landing page for AMO South Africa, a registered Non-Profit Company supporting the Seventh-day Adventist Church. This project serves as a temporary "Under Construction" portal while actively promoting the upcoming International Gospel Convention 2026.

---

## ✨ Key Features

* **Modern UI/UX:** Dark-themed aesthetic utilizing glassmorphism, dynamic gradients, and high-contrast amber accents.
* **Responsive Design:** Fully fluid layout that seamlessly adapts from ultrawide desktop monitors to mobile devices, featuring a custom animated hamburger menu.
* **Dynamic Countdown Engine:** Real-time, precision countdown timer tracking the kickoff of the Kenya Gospel Convention (April 2026).
* **Accessible Navigation:** Smooth-scrolling anchor links with offset calculations to prevent sticky-header overlap, paired with an intersection-observer "Back to Top" floating action button.
* **Optimized Accessibility:** 100/100 Lighthouse Accessibility score. Features semantic HTML (`<main>`, `<nav>`), WCAG AA compliant color contrast, and aria-labels.
* **Direct Social Integrations:** High-conversion, one-click WhatsApp and Facebook integration for immediate community engagement.

---

## 🛠 Tech Stack

This project leverages a modern, blazing-fast frontend stack:

* **Framework:** [React 18](https://react.dev/)
* **Build Tool:** [Vite 8](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
* Node.js (v18 or higher recommended)
* npm (or your preferred package manager like yarn/pnpm)

### Installation

1. **Clone the repository**
   ```bash
   git clone [https://github.com/YOUR-USERNAME/amo-south-africa.git](https://github.com/YOUR-USERNAME/amo-south-africa.git)

2. **Navigate to the project directory**
   ```bash
   cd amo-south-africa

3. **Install NPM packages**
   ```bash
   npm install

4. **Run the development server**
   ```bash
   npm run dev

5. **Build for production**
   ```bash
   npm run build
